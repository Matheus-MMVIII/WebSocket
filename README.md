# Java TCP Chat Server

A simple TCP client-server application built in pure Java, developed to study network communication, sockets, streams, and concurrent client handling.

The project implements a basic server using `ServerSocket` and clients using `Socket`, allowing the server to establish connections, exchange messages, identify connected users, and manage multiple client connections.

## Current Features

* TCP client-server communication
* Server built with Java `ServerSocket`
* Client communication using `Socket`
* Input and output stream handling
* Basic client identification
* Connected client management using `Map`
* Simple text-based communication protocol

## Learning Goals

This project is being developed incrementally to explore:

* TCP/IP communication
* Java networking APIs
* Sockets and streams
* Client-server architecture
* Multithreading and concurrency
* Message protocols
* Connection and session management
* Real-time communication
* WebSocket concepts

## Technologies

* Java
* TCP
* Java Sockets
* Java I/O
* Git

The project is intentionally built without frameworks to provide a deeper understanding of how network communication works at a lower level.
